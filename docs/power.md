# Мощность главной гипотезы: проверка без дилеров

Создано скриптом `experiments/power_check.py` 27.11.2026. Код: 8b49203. Машина: arm64, 18 ядер; счёт 27 мин.

## Метод

Дилеры влияют на стадность только через цену. По модели Фрея они умножают реакцию цены на поток остальных агентов на M = 1/(1 + λΓ_book), и чартисты видят тренд в M раз сильнее. Это эмулируется без дилеров: вес a2 ценового слагаемого в поле чартиста умножается на M — 1.25 для short (λ|Γ| = 0.2, правило размера книги из prereg), 1 для none, 1/1.2 для long.

Для каждой пары (a1, a2): полная сетка J из prereg (0–2, шаг 0.1), 60 репликаций на «конфигурацию», 1500 шагов, burn-in 500; J_c и тест Джонкхира–Терпстры — тем же кодом, что в основном анализе (`analysis/`). Сиды из отдельного потока, одинаковые для всех пар (a1, a2).

Мощность оценена повторной выборкой наблюдённых J_c (1000 выборок по n на конфигурацию, асимптотическое p). Такая оценка оптимистична: она считает наблюдённый эффект истинным. Через «/» — доля отвержений при α = 0.05 и при α/3 = 0.0167 (худший случай поправки Холма для трёх гипотез). Мощность при n = 30 — повторные выборки по 30 из всех посчитанных репликаций. Оценка по одной выборке шумная: при 30 репликациях на другом наборе сидов она отличалась в разы, поэтому считается по 60 репликациям.

κ — сила ценового канала: (a2/v1) × наклон регрессии лог-доходности на намагниченность чартистов, медиана по прогонам none в пределах ±0.2 от медианы J_c. Ценовое слагаемое поля содержит κ·m, то есть действует как добавка к глобальной связи a1.

Ни одного прогона с дилером здесь нет, поэтому это не взгляд на результат эксперимента. Эмуляция предполагает, что эффект дилеров на чартистов полностью описывается M; на прогонах с дилерами это проверяет проверка механизма: κ(short) > κ(none) > κ(long).
