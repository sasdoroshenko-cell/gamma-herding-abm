До регистрации запускались только отладочные развёртки базовой модели без дилера (`scripts/debug_sweep_J.py`, `docs/debug_sweep_J.png`); по ним выбраны a1 и диапазон сетки J. ## 1. Вопрос исследования

Как знак гаммы книги дилеров опционов, которые дельта-хеджируют свою позицию в базовом активе, меняет критическую силу локальной связи J_c, при которой рынок с книгой заявок переходит к стадному поведению?

## 2. Модель

**Механизм сопоставления.** Непрерывный двойной аукцион с книгой лимитных заявок (`ExchangeAgent`): ценовой приоритет, исполнение по цене встречной заявки, цена рынка — середина спреда, шаг цены 0.1. Рыночная заявка исполняется по лучшим встречным ценам до исчерпания объёма.

**Шаг симуляции.** Запись состояния → пересмотр настроений чартистов → все агенты действуют по одному разу в случайном порядке → выплата дивидендов и процентов → новый дивиденд.

**Популяция в базовой конфигурации (112 агентов):**

| Тип | Число | Доля |
|---|---|---|
| Шумовые трейдеры | 30 | 26.8% |
| Фундаменталисты | 20 | 17.9% |
| Чартисты (на кольце) | 35 | 31.3% |
| Маркет-мейкеры | 15 | 13.4% |
| Дилеры опционов | 12 | 10.7% |

**Чартисты.** Поле, определяющее смену настроения: U = a1·x + (a2/v1)·(dp/dt)/p + J·local, где x — глобальное мнение чартистов, local — среднее настроение соседей по кольцу (по 2 с каждой стороны). Правило смены настроения — по модели Lux & Marchesi (1999), формула ценового члена — по Samanidou, Zschischang, Stauffer & Lux (2007), ур. 17. Параметры: **a1 = 0.6**, a2 = 1, v1 = 0.1.

Почему a1 = 0.6: в модели Lux одно глобальное слагаемое даёт переход при a1 = 1. При a1 = 1 отладочная развёртка показала пик χ при J = 0–0.2, то есть на краю сетки, и сдвиг J_c вниз при короткой гамме был бы ненаблюдаем. При a1 = 0.6 глобальная стадность сама по себе докритична, переход вызывается локальной связью, пик χ — при J ≈ 0.6–1.0.

**Маркет-мейкеры.** Котируют обе стороны каждый шаг; запас управляется сдвигом обеих котировок в одну сторону (не больше ширины спреда); на каждой стороне всегда не меньше `min_quote` лотов.

**Что ещё может поменять калибровка (до тега `config-v1`, не позже 29.11.2026):** число маркет-мейкеров (так, чтобы их доля оставалась не меньше 10%), их `softlimit` и `min_quote`, доля шумовых трейдеров и разброс цен их заявок, объём начальной книги. Всё остальное в этом документе калибровкой не меняется.

## 3. Дилер и конфигурации

**Книга дилеров.** Все 12 дилеров одинаковы, общая книга делится между ними поровну. Каждый держит лестницу из 4 стрэддлов (колл + пут с одним страйком): каждые 15 шагов выпускается новый стрэддл со сроком 60 шагов и страйком, равным текущей цене; стрэддл закрывается за 5 шагов до экспирации. Контрагенты по опционам внешние (клиенты вне модели): расчёты по опционам меняют только деньги дилера и не создают заявок в книге.

**Оценка опционов.** Блэк–Шоулз с дивидендной доходностью: r — безрисковая ставка модели (5·10⁻⁴ за шаг), q — текущий дивиденд, делённый на цену. Волатильность — скользящее стандартное отклонение лог-доходностей за **w = 50 шагов**, но не меньше **σ_floor = 0.003 за шаг** (без нижней границы при неподвижной цене гамма около денег неограниченно растёт).

**Хедж.** Каждый шаг дилер считает дельту своей книги и рыночной заявкой доводит позицию в базовом активе до дельта-нейтральной. Размер хеджевой заявки не ограничивается.

**Три конфигурации** различаются только знаком книги при одинаковом размере n₀ стрэддлов:

| Конфигурация | Книга | Гамма книги | Хедж после роста цены |
|---|---|---|---|
| short | дилеры продали n₀ стрэддлов | < 0 | покупка (по тренду) |
| none | книга пуста (дилеры не торгуют) | 0 | — |
| long | дилеры купили n₀ стрэддлов | > 0 | продажа (против тренда) |

В конфигурации none дилеры присутствуют с пустой книгой, поэтому число агентов одинаково во всех конфигурациях.

**Правило размера книги n₀.** Размер выбирается заранее по модели обратной связи Фрея, а не по результатам. n₀ — такое число стрэддлов, при котором прогнозный λ·|Γ_book| = 0.2 (множитель Фрея M = 1/(1 − 0.2) = 1.25 при короткой гамме), где:
- λ — сдвиг цены на единицу объёма рыночной заявки, оценённый на откалиброванной модели без дилера при J_ref: λ ≈ (FVS(Q) − спред)/Q, Q = 10, 20, 50, среднее по 10 сидам;
- Γ_book = n₀ · Γ_straddle, где Γ_straddle — гамма одного стрэддла около денег по Блэку–Шоулзу при S = 100, среднем оставшемся сроке лестницы и откалиброванной σ.

n₀ считается по этому правилу после калибровки и записывается в конфигурацию с датой до первого полного прогона. Значение округляется до целого, кратного 12.

**Размеры для анализа чувствительности:** n ∈ {0.25; 0.5; 1; 2; 4}·n₀. При 4·n₀ прогнозный λ|Γ| = 0.8 < 1, обратная связь по Фрею ещё устойчива.

## 4. Протокол прогонов

- **Сетка J:** от 0.0 до 2.0 с шагом 0.1 (21 точка).
- **Длина прогона:** 1500 шагов; первые 500 — burn-in; все статистики считаются по шагам 501–1500.
- **Репликации:** 30 на каждую конфигурацию. Каждая точка сетки в репликации — отдельная симуляция с собственным сидом.
- **Сиды:** сид = 1 000 000·(номер конфигурации) + 10 000·(номер размера книги) + 100·(номер точки J) + (номер репликации). Потоки сидов у конфигураций не пересекаются, поэтому выборки независимы.
- **J_ref** (для калибровки и оценки λ): наибольшая точка сетки, где у откалиброванной модели без дилера среднее |m| ≤ 0.3 (по 3 сидам отладочной проверки).
- **J_fix** (для гипотезы В1): наименьшая точка сетки, где у откалиброванной модели без дилера среднее |m| ≥ 0.8 (по 3 сидам отладочной проверки). По нынешней отладочной развёртке это J ≈ 1.1.

**Порядок перед полными прогонами:** калибровка → отладочная проверка откалиброванной модели без дилера (J_ref, J_fix, диапазон сетки) → оценка λ → n₀ → проверка механизма хеджа (раздел 6) → полные прогоны.

## 5. Гипотезы

Общие условия: α = 0.05, поправка Холма на три гипотезы, 30 независимых репликаций на конфигурацию.

### Главная гипотеза (Г)

- **Величина.** Критическая связь J_c одной репликации: J_c = argmax_J χ(J), где χ(J) = N_ch · Var_t(|m_t|), m_t = (n_opt − n_pess)/N_ch — намагниченность чартистов на шаге t, дисперсия по шагам 501–1500. Если максимум внутри сетки, J_c уточняется вершиной параболы через три точки вокруг него.
- **Направление и обоснование.** J_c(short) < J_c(none) < J_c(long). При короткой гамме хеджевый поток трендовый: дилеры покупают после роста цены и продают после падения. Через ценовой член в поле чартистов это работает как дополнительная положительная связь, поэтому стадность возникает при меньшем J. Длинная гамма даёт контртрендовый поток и обратный эффект (Frey & Stremme, 1997; Gennotte & Leland, 1990; множитель Фрея M = 1/(1 + λΓ)).
- **H₀:** распределения J_c в трёх конфигурациях одинаковы.
- **H₁:** J_c(short) ≤ J_c(none) ≤ J_c(long), хотя бы одно неравенство строгое.
- **Тест:** Джонкхира–Терпстры, перестановочное p-значение (10 000 перестановок).

**Уточнение по сравнению с утверждённой формулировкой:** χ считается по |m_t|, а не по m_t. В упорядоченной фазе конечной системы знак m может перескакивать между «почти все оптимисты» и «почти все пессимисты»; тогда Var(m) раздувается уже после перехода, и пик смещается. Использование |m| — стандартный приём для конечных систем; сама гипотеза и её направление не меняются.

### Вспомогательная гипотеза 1 (В1)

- **Величина.** σ — стандартное отклонение лог-доходностей по шагам 501–1500 в прогоне при J = J_fix.
- **Направление и обоснование.** σ(long) < σ(none) < σ(short): хеджирование с короткой гаммой усиливает колебания цены, с длинной — гасит (Frey & Stremme, 1997; эмпирически — Ni, Pearson, Poteshman & White, 2021).
- **H₀:** распределения σ в трёх конфигурациях одинаковы.
- **H₁:** σ(long) ≤ σ(none) ≤ σ(short), хотя бы одно неравенство строгое.
- **Тест:** Джонкхира–Терпстры, перестановочное p-значение (10 000 перестановок).

### Вспомогательная гипотеза 2 (В2)

- **Величина.** Площадь петли гистерезиса A = Σ_J |m↑(J) − m↓(J)| · ΔJ. В одном длинном прогоне J сначала проходит сетку от 0 до 2, затем обратно от 2 до 0; на каждой ступени 200 шагов, первые 50 не учитываются, m↑(J) и m↓(J) — среднее |m| по остальным 150 шагам. Перед первой ступенью — 500 шагов burn-in при J = 0. Состояние между ступенями не сбрасывается.
- **Направление и обоснование.** A(short) > A(none): гамма зависит от расстояния до страйка, поэтому обратная связь нелинейна, и при короткой гамме переход становится разрывным. Нелинейный хеджевый спрос превращает малые шоки в скачки цены (Gennotte & Leland, 1990); при λ|Γ| → 1 множитель Фрея растёт без ограничений.
- **H₀:** распределения A в конфигурациях short и none одинаковы.
- **H₁:** A(short) стохастически больше A(none).
- **Тест:** Манна–Уитни, односторонний.

## 6. План анализа

**Размеры эффекта (у каждого теста — с бутстрэп-ДИ 95%, 10 000 повторов):**
- Г: разности медиан J_c(none) − J_c(short) и J_c(long) − J_c(none); τ Кендалла между порядком конфигурации (short = 1, none = 2, long = 3) и J_c.
- В1: отношения медиан σ(short)/σ(none) и σ(none)/σ(long).
- В2: P(A_short > A_none) = U/(n₁n₂) и разность медиан A.

**Поправка Холма** применяется к трём p-значениям основных тестов при α = 0.05.

**Предпосылки.** Независимость выборок обеспечена разными потоками сидов. Шкала порядковая. Сходство формы распределений проверяется по ящичковым диаграммам и оценкам плотности; если формы заметно различаются, результат теста Манна–Уитни трактуется как стохастическое доминирование.

**Проверка механизма — условие запуска полных прогонов, а не гипотеза.** На отладочном масштабе и затем на полных данных: корреляция хеджевого потока дилеров с доходностью предыдущего шага должна быть положительной при short и отрицательной при long. Если это не так, дилер исправляется до полных прогонов, и это записывается в журнал.

**Разведочные анализы (в поправку Холма не входят):**
- Чувствительность: при каждом из 5 размеров книги — ΔJ_c = med J_c(short) − med J_c(none) с бутстрэп-ДИ и тест Джонкхира–Терпстры. Вывод считается устойчивым, если знак эффекта не меняется; ожидается, что |ΔJ_c| растёт с размером книги.
- Модель Фрея: прогнозные σ(short)/σ(none) и σ(long)/σ(none) против наблюдаемых при 5 размерах книги.
- Гистерезис для конфигурации long — описательно.

**Отчёт по каждому тесту:** H₀ и H₁, α, статистика, p-значение, размер эффекта с ДИ, число репликаций, вывод словами, поправка Холма. Отрицательный результат отчитывается так же подробно, как положительный.

## 7. Прерванные прогоны

Прогон считается прерванным, если симуляция остановилась с ошибкой (например, одна сторона книги опустела и цена не определена). Шаг остановки записывается.
- **Г:** точка сетки с прерванным прогоном исключается из χ(J) этой репликации; J_c считается по остальным точкам. Если в репликации прервано больше 3 точек из 21, репликация заменяется следующей по потоку сидов.
- **В1, В2:** прерванный прогон заменяется следующим сидом из потока.
- Число прерванных прогонов и замен по каждой конфигурации указывается в отчёте. Молча прогоны не выбрасываются.

**Пик на краю сетки.** Если argmax χ приходится на J = 0 или J = 2, значение J_c берётся равным краю сетки и помечается. Доля таких репликаций указывается в отчёте; тест Г дополнительно пересчитывается без них (разведочно).

## 9. Что можно менять после регистрации

Только следующее, и только до первого полного прогона с дилером:
1. Параметры калибровки из раздела 2 — до тега `config-v1`.
2. Диапазон сетки J — если на откалиброванной модели без дилера пик χ оказался на краю сетки или ниже J = 0.3 (тогда сдвигу вниз не хватает места). Шаг остаётся 0.1 или мельче.
3. J_ref, J_fix и n₀ — вычисляются по правилам разделов 3–4, а не выбираются.
4. Исправления ошибок в коде, не меняющие гипотез, тестов и протокола.
